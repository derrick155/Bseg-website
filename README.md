# Black Summit Enterprise Group website source

This package was reconstructed from the current Netlify production deploy.

## Contents
- `index.html` — current live site source, including inline CSS and JavaScript.

## Important
- The funding application uses Netlify Forms (`data-netlify="true"`).
- Keep the form name `financing-application` unchanged unless intentionally migrating form handling.
- Create a Git repository from this folder, then connect that repository to Netlify.
- Use Netlify Deploy Previews / branch deploys for Business Solutions changes before merging to production.
- Do not publish Business Solutions changes to the production branch until reviewed.

This package does not change the live site.
